📱 把工具箱装到主屏幕

📲 一键安装，离线可用

安装后像 App 一样全屏打开，免浏览器地址栏，秒开即用（数据本地处理，不上传）。

📱 iPhone / iPad（Safari）
  1. 点击底部的 「分享」按钮 ↑
  2. 在弹出菜单里选 「添加到主屏幕」
  3. 名称可改，点右上角 「添加」 完成
  4. 返回桌面就能看到「托托工具箱」图标
🤖 安卓手机（Chrome / 华为 / 小米浏览器）
  1. 点击右上角 「⋮」菜单（或浏览器地址栏右侧的「安装」）
  2. 选择 「安装应用 / 添加到主屏幕」
  3. 在弹窗里点 「安装」 即可
  4. 如果没看到菜单项，先 刷新一下页面，浏览器才会识别这是 PWA
💡 建议使用手机自带的 Chrome 或系统浏览器，避免第三方 App 内置浏览器拦截安装步骤。
💻 电脑（Chrome / Edge）
  1. 浏览器地址栏右侧会出现 「安装」图标 ⊕，点击即可
  2. 或点浏览器右上角 「⋮」→「将此应用作为应用安装」
  3. 安装后桌面会有图标，独立窗口运行，不受标签页影响
（浏览器会弹出确认框）
⚠️ 无法下载 / 打不开？先清除浏览器缓存

安装按钮不出现、点击没反应、或打开后空白，多半是浏览器缓存了旧版本。按下面步骤清一次缓存（只勾「缓存的图片和文件」即可，不必清 Cookie / 密码），再刷新页面就能装。

💻 电脑端
  • Chrome / Edge（快捷键）：按 Ctrl+Shift+Delete（Mac 为 ⌘+Shift+Delete）→ 时间范围选「所有时间」→ 只勾「缓存的图片和文件」→「清除数据」，然后按 F5 刷新。
  • Firefox（快捷键）：按 Ctrl+Shift+Delete → 时间范围「全部」→ 只勾「缓存」→「立即清除」，再刷新。
  • Mac Safari：顶部「Safari」→「设置」→「高级」→ 勾选「在菜单栏显示『开发』菜单」→ 顶部「开发」→「清空缓存」（或按 ⌥+⌘+E），再刷新。
  • 通用 F12 法（任意浏览器）：按 F12 打开开发者工具 → 切到「网络(Network)」面板勾选「禁用缓存(Disable cache)」→ 右键地址栏刷新按钮选「清空缓存并硬性重新加载」。
📱 手机端
  • iPhone Safari：「设置」→「Safari 浏览器」→「清除历史记录与网站数据」（会连同历史一起清，不影响已装主屏图标）→ 回到 Safari 重新打开本工具箱网址。
  • iPhone Chrome：点右下角「⋯」→「设置」→「隐私和安全」→「清除浏览数据」→ 只勾「缓存的图片和文件」→「清除浏览数据」。
  • Android Chrome：点右上角「⋮」→「设置」→「隐私和安全」→「清除浏览数据」→ 时间范围「所有时间」→ 只勾「缓存的图片和文件」→「清除数据」，再重新打开页面。
  • Android 其他浏览器（华为 / 小米 / 系统浏览器）：在浏览器「设置」→「隐私」/「清除数据」中找「缓存」项清除；清除后重新打开工具箱网址，待页面加载完再点安装。

清完缓存若仍无法下载，请改用手机自带 Chrome / 系统浏览器（微信、QQ 等内置浏览器可能拦截安装），并先刷新一次页面让浏览器识别为可安装 PWA。
