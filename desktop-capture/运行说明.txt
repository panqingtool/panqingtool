托托长截图（电脑版）· 使用说明
============================

这是一个 Windows 小程序，用来截取电脑上任意窗口（Word / WPS / 微信 / 资源管理器 / 浏览器外页面 / 桌面）的整窗长图。

【无需安装 Python · 直接双击 exe】

1. 先把整个 zip 解压到一个文件夹（例如桌面新建一个“desktop-capture”文件夹，把文件全放进去）。
2. 双击里面的 scroll_capture.exe，程序直接运行，不用装 Python、不用跑任何脚本。
3. 若浏览器 / 系统提示“可能有害”，点“保留”或“仍要运行”即可（这是 Windows 对未知 exe 的误报；程序纯本地运行，不上传任何数据）。

【使用方法】
1. 运行后点“开始截取”；
2. 程序会最小化到任务栏，请点一下你要截的窗口使其置顶；
3. 程序自动逐屏截图 + 模拟滚轮下滚，直到滚到底；
4. 弹出保存框，选位置存成 PNG 即可。

【参数】
- 每次滚动比例：滚轮一次滚多少。内容密集易拼缝就调小（0.5~0.6），内容很长就调大（0.8~0.9）。
- 每帧等待(ms)：截完一屏等多少毫秒再截下一屏。电脑慢 / 滚动有动画就调大（600~800）。

【常见问题】
- 双击 exe 没反应 / 一闪而过：确认解压后双击的是 scroll_capture.exe；如仍不行，右键“以管理员身份运行”试一次。
- 截出来的图是空白/黑屏：先确认你要截的窗口确实置顶，且没有被别的窗口挡住。
- 截到一半想停：把鼠标甩到屏幕左上角，程序会自动中止。
