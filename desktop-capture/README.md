# 托托长截图（电脑版）

给 **panqingtool 在线工具箱** 里的「长截图 / 滚动截图」配的电脑版小程序。  
网页版只能截网页（且其它网站要手动滚），**本程序可以截电脑上任意软件窗口的整窗长图**——Word、WPS、微信、资源管理器、浏览器外页面、桌面都行。

> 为什么需要它？浏览器里的网页受安全限制，截不到浏览器外面的软件窗口。要做到「在任何页面都能截长图」，必须是一个装在电脑上的小程序。

---

## 一、使用（无需安装 Python）

1. 在本站「长截图 / 滚动截图」里点 **⬇️ 下载电脑版小程序（安装包）**，得到 `desktop-capture.zip`。
2. 把 zip **解压**到一个文件夹（例如桌面新建 `desktop-capture` 文件夹，把文件全放进去）。
3. **双击 `scroll_capture.exe`** 即可运行——它已经把 Python 和所有依赖打包进去了，不用装任何东西。
4. 若 Windows / 浏览器提示“可能有害”，点“保留 / 仍要运行”即可（程序纯本地运行，不上传任何数据）。

> 打包是在云端（GitHub Actions 的 Windows 运行器，用 Python 3.11 构建）完成的，因此你的电脑是 Python 3.14 也完全不影响使用。

## 二、怎么截一张长图

1. 双击运行后，点窗口里的 **「▶ 开始截取」**。
2. 程序会缩到后台，**先点一下你要截的窗口**（让它置顶、变成当前窗口）。
3. 程序自动开始：逐屏截图 → 模拟滚轮往下滚 → 再截 → 直到滚到底。
4. 滚到底后弹「保存」对话框，选个位置存成 `PNG` 即可。

### 参数说明

- **每次滚动比例**：滚轮一次滚多少。窗口内容很密集、容易拼出缝隙就调小（0.5~0.6）；内容很长就调大（0.8~0.9）。
- **每帧等待(ms)**：截完一屏等多少毫秒再截下一屏。电脑慢 / 滚动有动画就调大（600~800）。

## 三、常见问题

- **截出来中间有缝隙 / 重叠**：把「每次滚动比例」调小（如 0.5），等画面稳定了再截下一屏。
- **截到一半停了 / 没到底**：可能滚动判定太灵敏，把「每帧等待」调大；或窗口不是当前置顶窗口，重来一次先点窗口。
- **紧急停止**：把鼠标**甩到屏幕左上角**，程序会自动中止（pyautogui 的防错机制）。
- **双击 exe 没反应**：确认解压后双击的是 `scroll_capture.exe`；或右键“以管理员身份运行”试一次。
- **截到的是整窗含标题栏**：这是预期行为（要截的就是整个窗口）。只想截客户区内容的话，把窗口拉到合适大小再截。

## 四、原理（简述）

1. 取当前置顶窗口的矩形区域（`GetForegroundWindow` + `GetWindowRect`）。
2. 用 `pyautogui` 逐屏截该区域；模拟鼠标滚轮下滚。
3. 两帧「几乎完全一样」即判定滚到底。
4. 用**重叠检测**把所有帧拼成一张超长图（逐行采样 RGB 签名，找相邻帧重合像素量，按重合量裁剪拼接），保存 PNG。

与在线工具箱网页版共用同一套重叠拼接算法，拼接可靠、不依赖网络。

## 附：自行重新打包（可选，需本机有 Python）

如果你改了 `scroll_capture.py` 想自己出 exe，在装好 Python 后执行：

```bat
pip install -r requirements.txt pyinstaller
build_exe.bat
```

打包完成后在 `dist\scroll_capture.exe`。日常使用无需这一步——站点提供的 `desktop-capture.zip` 里已经是打包好的 exe。
